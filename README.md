# Portfolio – Johann Balzereit

Personal portfolio website showcasing my projects and skills as a self-taught frontend developer.

## 🔗 Live Demo
[https://johann-2909.github.io/Portfolio/](https://johann-2909.github.io/Portfolio/)

## Features
- Dark mode with LocalStorage persistence
- DE/EN language toggle
- Contact form with validation and EmailJS integration
- Scroll animations with IntersectionObserver
- Fully responsive design
